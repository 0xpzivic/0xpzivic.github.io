This is the first post.

I've been meaning to write more — about the things I build, the decisions behind them, and the bits I learn along the way. So here we are.

## Why a blog (and not just X / LinkedIn)

A few reasons:

1. **I own the URL.** Posts don't disappear behind an algorithm or a paywall.
2. **Long-form forces clearer thinking.** A thread is fine; a post is better.
3. **It's a forcing function.** Writing publicly is the fastest way to find out what I actually believe.

## What to expect

- Notes on engineering — mostly TypeScript / Python / web stuff.
- Notes on building product with small teams.
- The occasional opinion that I'll probably regret in six months.

If any of that interests you, the [RSS feed](/rss.xml) is live and the source for this site is on [GitHub](https://github.com/0xpzivic/0xpzivic.github.io).
